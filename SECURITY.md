# Security Policy

## Reporting a vulnerability

Please report security problems privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue for them.

Include the version (top of `tinyfilemanager.php`), the PHP version and the steps to reproduce. You will get a reply as soon as possible, and credit in the changelog if you wish.

Problems that also exist in the original [Tiny File Manager](https://github.com/prasathmani/tinyfilemanager) should be reported to its maintainers as well.
